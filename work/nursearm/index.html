NurseArm: An Assistive Robot Arm for Sorting Medication

A robot arm that sorts pills on a schedule, and what it taught us about long tasks

Simone Utili, Panagiotis Sarikas, Javier Gil, Miguel Ballesteros Delgado

CodeSmolVLA

NurseArm is a tabletop assistant for medication routines. A six-joint SO-101 arm with two cameras, one above the workspace and one on the wrist, is connected to a web console, voice input, and a language-model agent.

The agent never sends motor commands itself. It can only call a fixed set of skills, which keeps a language model at a safe distance from the hardware.

  • Imitation Learning (ACT / SmolVLA)
  • MCP
  • SO-101 Arm
  • Teleoperation

What we built

  • Robot. A six-joint SO-101 arm with one camera above the workspace and one on the wrist.
  • Interface. A web console and voice input.
  • Agent. A language-model agent that calls skills through an MCP server instead of sending motor commands.
  • Skills. Medication routines triggered from a calendar, simple straight-line moves, and policies learned by imitation for sorting pills and handing them over: ACT and SmolVLA, a compact open-source VLA.

Collecting the data

We made the physical setup as clean and controlled as we could: an isolated workspace, no background clutter, fixed lighting. Then we stayed up all night and recorded nearly 200 demonstrations, guiding the robot through each one with a second arm that it copies, convinced that a clean setup would be enough for the policy to work.

What we learned

It was not enough. When we ran the learned policy, it did not succeed often enough for a reliable live demo.

Did it need even cleaner data, or was the task simply too long for a single policy without breaking it into steps? In hindsight, probably the second. That open question was the most valuable thing we took home from the weekend.
